# Crime Pattern & Geospatial Analysis

Tableau-based analysis of multi-year crime data to identify crime trends, arrest patterns and geographic hotspots.

## Tools

- Tableau
- Data Analysis
- Geospatial Visualization

## Project Overview

Analyzed crime data across multiple years to identify temporal trends, crime categories, arrest patterns and geographic hotspots.

The Tableau dashboard provides interactive visual analysis through maps, filters and trend-based views.
